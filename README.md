# HOKSH Business

واجهة عربية لإدارة نشاط تجاري صغير، مبنية كنسخة MVP محلية تعمل من المتصفح.

## الوظائف الموجودة في نسخة MVP
- إنشاء حساب مالك محلي وتسجيل الدخول على المتصفح الحالي.
- إضافة المنتجات وتعديلها وحذفها، مع سعر البيع والتكلفة والرصيد الافتتاحي.
- نقطة بيع: اختيار المنتجات، تكوين سلة، تأكيد الفاتورة، وخصم الكمية من المخزون.
- تسجيل المشتريات والتوريدات وزيادة المخزون وتحديث تكلفة الوحدة.
- إدارة العملاء وربط العميل بفاتورة البيع.
- لوحة مؤشرات وتقارير محسوبة من العمليات المسجلة، دون بيانات تجريبية.
- نسخ احتياطي JSON واستيراد النسخة الاحتياطية.
- حفظ تلقائي في LocalStorage وتحديث PWA cache.

## حدود مهمة قبل الاستخدام التجاري متعدد الأجهزة
هذه النسخة **محلية على المتصفح والجهاز**. حساب المالك وكلمة المرور مخزنان محليًا (كلمة المرور بصمة SHA-256)، ولا يوجد خادم مصادقة أو قاعدة بيانات سحابية أو مزامنة بين الأجهزة أو عزل آمن بين الشركات. لا تعتبر تسجيل الدخول المحلي حماية إنتاجية، ولا تستخدم النسخة كمنصة متعددة المستخدمين أو لتخزين بيانات شديدة الحساسية. يجب ربط Supabase Auth + PostgreSQL + سياسات RLS واختبارها قبل إطلاق حسابات حقيقية متعددة الأجهزة.

## النشر
تُنشر الواجهة عبر GitHub Pages. مفاتيح Supabase العامة فقط يمكن وضعها في الواجهة بعد إعداد RLS؛ يمنع وضع service-role key أو أي سر إداري في JavaScript العام.
