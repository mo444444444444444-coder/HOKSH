# HOKSH — Final publication checklist

## Completed by the project
- Web/PWA version.
- GitHub Pages deployment.
- Privacy policy page.
- Android project.
- Target SDK 36.
- Release AAB build workflow.
- Successful release AAB build verified in GitHub Actions.
- Store listing draft.
- Play preparation documentation.

## Still owned by the developer account
1. Create/verify Google Play Console developer account.
2. Complete developer identity/payment/profile information requested by Google.
3. Create the HOKSH app in Play Console using package `com.hoksh.editor`.
4. Configure Play App Signing/upload signing.
5. Complete store listing, screenshots, app icon/graphics, category, contact details and content rating.
6. Complete the Data Safety form so it exactly matches the app's real data practices.
7. If the account is a new personal developer account subject to Google's testing rule: run a closed test with at least 12 testers continuously opted in for 14 days.
8. Apply for production access.
9. Upload the signed AAB and submit the production release.
10. Wait for Google's review and publication.

## Important
Never commit a private signing key, Google password, payment information, or personal identity documents to this repository.
