# HOKSH Business

واجهة أولية عربية لإدارة النشاط التجاري والمبيعات والمنتجات والمخزون.

## الحالة الحالية
- لوحة تحكم RTL متجاوبة للهاتف والكمبيوتر.
- مؤشرات أداء ورسوم بيانية توضيحية ببيانات تجريبية.
- عرض المنتجات وإضافة منتج والبحث في القائمة (داخل جلسة الصفحة).
- قائمة تنقل للأقسام الأساسية.

## ما لم يُنفذ بعد
تسجيل الدخول، قاعدة البيانات، تعدد الشركات والفروع، المبيعات الفعلية، المخزون الدائم، المشتريات، الصلاحيات، المزامنة دون اتصال، والتقارير المحاسبية. لا تستخدم هذه النسخة لإدارة أموال أو مخزون حقيقي قبل ربط الخدمات واختبارها.

## النشر
المشروع منشور كواجهة ثابتة عبر GitHub Pages. الخدمات الخلفية تحتاج إعدادًا منفصلًا وآمنًا. لا تضع مفاتيح سرية أو مفاتيح خدمة إدارية في ملفات الواجهة.

## التطوير
يتم العمل على فرع مستقل قبل دمج التغييرات إلى `main` حفاظًا على الموقع الحالي.
