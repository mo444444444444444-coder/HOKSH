# حوكش HOKSH

منصة عربية تجمع المذاكرة والأدوات والسبورة الرقمية، مع الحفاظ على أدوات PDF الحالية. المطور: محمد شعبان محارب.

## الوظائف الحالية
- فتح ملفات PDF واستخدام القلم والتظليل والأشكال والنص والممحاة والتراجع/الإعادة.
- سبورة رقمية جديدة بمقاسات جاهزة.
- تصدير PDF وصور للصفحات.
- قائمة بالملفات الحديثة وإعدادات العرض.
- جولة تعريفية بالواجهة ودعم فني.
- خطة مذاكرة محلية: إضافة المهام وتعليمها كمكتملة وحذفها.
- أداة محلية لتحويل الصور إلى PNG أو JPEG أو WebP وتغيير العرض والجودة، دون رفع الصور إلى خادم.
- إعدادات تطبيق ويب قابل للتثبيت (PWA) وتحديث ملفات الكاش.

## ملفات مهمة
- `index.html`: الواجهة الحالية ومحرر PDF والسبورة.
- `hoksh-platform.js`: مركز المنصة وخطة المذاكرة وأداة تحويل الصور.
- `sw.js` و`manifest.webmanifest`: ملفات التثبيت والكاش.
- `hoksh-cloud.js` و`supabase-config.js`: تكامل الحسابات والملفات السحابية.
- `SUPABASE-SETUP-AR.md`: تعليمات إعداد الخدمة السحابية.

## ملاحظات مهمة
- خطة المذاكرة تُحفظ محليًا على الجهاز الحالي؛ لا تتزامن مع الأجهزة الأخرى.
- أداة الصور تعمل داخل المتصفح ولا ترفع الملف إلى خادم.
- وجود كود الحسابات السحابية لا يعني أن جميع إعدادات Supabase قد تم اختبارها؛ راجع تعليمات الإعداد واختبارات الصلاحيات قبل الاعتماد عليها.
- اختبارات GitHub Actions تتحقق من سلامة صياغة JavaScript وملفات التطبيق الأساسية، لكنها لا تغني عن اختبار الاستخدام الفعلي على الهاتف والكمبيوتر.
- لا تضع كلمات مرور أو مفاتيح سرية في ملفات المستودع.
